# Digital Music Store Database Analysis (SQL)

## Overview

This project focuses on analyzing a digital music store database using SQL. The objective was to solve real-world business problems by writing SQL queries that extract meaningful insights from customer, sales, artist, album, and invoice data.

The project demonstrates practical SQL skills such as data retrieval, filtering, joins, aggregation, grouping, subqueries, Common Table Expressions (CTEs), and window functions.

---

## Database

The project uses a relational database containing information about:

- Customers
- Employees
- Artists
- Albums
- Tracks
- Genres
- Playlists
- Invoices
- Invoice Items

The database represents a digital music store where customers purchase songs from different artists and genres.

## Tools Used

- SQL
- PostgreSQL (compatible with most SQL databases)

## Project Objectives

The goal of this project is to answer business-related questions using SQL and gain insights into customer behavior and sales performance.

---

## Business Questions Solved

Some of the questions explored in this project include:

- Who is the senior-most employee based on job title?
- Which countries generate the highest number of invoices?
- What are the top-selling music genres?
- Which customers have spent the most money?
- Who is the best customer overall?
- Which city generates the highest revenue?
- Which artists have the highest number of tracks sold?
- Which customers listen to Rock music?
- What are the most popular artists in each country?
- How much has each customer spent on the best-selling artist?
